# 3D Anatomy Trainer

Part of Active Transport's free study tools (https://activetransport.app). Class structure lists on 3D models:
- **Find it:** you get a name and click the structure.
- **Name it:** a structure is highlighted and you type its name.
- **Explore:** click anything to see what it is.
